# Release v0.4.0 — WarehouseFlow SGA

**Fecha:** 2026-09-01 (planificado)

## 🚀 Highlights

### Realtime con InsForge
Suscripciones en tiempo real para actualizaciones de inventario, órdenes y picking. Sin polling, sin refrescar.

### PWA (Progressive Web App)
Instalable en móviles y tablets como app nativa. Offline support con Service Worker.

### Dashboard con gráficos reales
Charts interactivos con datos en tiempo real. Eliminados todos los datos hardcoded.

### Roles y permisos en UI
Los componentes se adaptan al rol del usuario. Menús, botones y vistas se ocultan/muestran según permisos.

---

## 📋 Plan de cambios

### Añadido

#### Realtime
- Suscripciones a cambios en `products`, `orders`, `picking`
- Indicador de conexión en tiempo real
- Notificaciones toast para cambios importantes
- Presencia de operarios conectados

#### PWA
- `manifest.json` con iconos y theme color
- Service Worker para cache de assets
- Offline fallback page
- Install prompt en móvil

#### Dashboard mejorado
- Gráfico de volumen diario con datos reales
- Gráfico de stock por categoría
- Timeline de actividad reciente
- KPIs con comparativa temporal (vs semana anterior)

#### Roles en UI
- Sidebar dinámico según rol
- Botones de acción según permisos
- Vista de gestión de usuarios (solo admin)
- Auditoría de acciones

#### Tests
- Tests unitarios con Vitest
- Tests de integración para API routes
- Tests E2E con Playwright

### Cambiado

- Dashboard carga datos via GraphQL multi-resource
- Componentes usan `useQuery` de Apollo en vez de fetch
- Navegación usa slugs en URLs
- Auth persiste sesión con refresh token

### Eliminado

- Datos hardcoded del dashboard
- Fetch directo a `/api/*` (reemplazado por API Manager)
- Dependencias no utilizadas

## 🔧 Implementación técnica

### Realtime
```typescript
import { useSubscription } from "@apollo/client";

const { data } = useSubscription(ON_PRODUCT_UPDATED, {
  variables: { category: "Palets" }
});
```

### PWA
```json
// manifest.json
{
  "name": "WarehouseFlow SGA",
  "short_name": "WarehouseFlow",
  "start_url": "/works/whm-withnext",
  "display": "standalone",
  "theme_color": "#0a0a0a",
  "background_color": "#0a0a0a"
}
```

### Roles
```typescript
import { useAuth } from "./lib/auth-context";

const { user } = useAuth();
const canEdit = ["admin", "manager", "supervisor"].includes(user?.role);
```
