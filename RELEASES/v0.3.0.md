# Release v0.3.0 — WarehouseFlow SGA

**Fecha:** 2026-09-01

## 🚀 Highlights

### GraphQL + Apollo
API GraphQL completa con Apollo Server 5 + Apollo Client 4. Queries multi-resource que cargan el dashboard completo en una sola llamada.

### API Manager
Patrón singleton para gestión de APIs con URL builder, path params y typed helpers. Centraliza toda la comunicación HTTP.

### Slugify SEO-friendly
Todas las entidades usan slugs en vez de IDs en las URLs. Mejor SEO y URLs legibles.

### Autenticación + Storage
Sistema de auth con roles (admin, manager, supervisor, operator, picker, viewer), Google SSO documentado, y bucket de storage para archivos.

## 📦 Instalación

```bash
bun install

```

## 🔧 Scripts nuevos

```bash
# GraphQL
curl -X POST http://localhost:3000/api/graphql \
  -H "Content-Type: application/json" \
  -d '{"query": "{ dashboardStats { totalProducts } }"}'

# API Manager
import { api, initWarehouseApi, productsApi } from "./lib";
initWarehouseApi("https://8cc79ec9.insforge.site");
const products = await productsApi.list({ category: "Palets" });

# Slugify
import { slugify } from "./lib";
slugify("Palet Europeo 120x80") // "palet-europeo-120x80"
```
