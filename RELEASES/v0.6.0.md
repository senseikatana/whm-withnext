# Release v0.6.0 — WarehouseFlow SGA

**Fecha:** 2026-09-01

## 🚀 Highlights

### Dynamic basePath — Un solo build, dos dominios
La app detecta automáticamente si sirve bajo un subpath (`/works/whm-withnext`) o en raíz. Sin env vars de build, sin builds separados.

### DeepSeek AI integrado
Migrado de Gemini a DeepSeek para todas las funciones de IA: auto-completar formularios, copilot, generación de rutas y respuestas WhatsApp.

### Realtime con InsForge
Triggers en base de datos que publican cambios en tiempo real: productos, órdenes, picking, dashboard e inventario.

### Interfaces centralizadas
Todos los tipos TypeScript organizados en `app/interfaces/` por categoría.

### Asistencia IA en CRUD
Botón "Auto-completar IA" en modales de creación que genera datos realistas via DeepSeek.

---

## 📋 Cambios

### Añadido

- `app/lib/base-path.ts` — detección dinámica de subpath en runtime
- `app/utils/ai-api.ts` — API DeepSeek con retry logic
- `app/lib/normalize.ts` — normalizadores snake_case → camelCase
- `app/interfaces/` — 7 archivos con todos los tipos centralizados
- Realtime: 5 canales con triggers (`products`, `orders`, `picking`, `dashboard`, `inventory`)
- Botón "Auto-completar IA" en modales CRUD
- `.env.local` con valores reales de InsForge

### Eliminado

- Vista móvil (MobileAppSimulator) del header y render
- Gemini API — reemplazado por DeepSeek
- `app/utils/gemini-api.ts`

### Corregido

- `loadData` causaba bucle infinito (useCallback fix)
- Flasheo en carga inicial (basePath + useCallback)
- `.env.local` tenía valores placeholder
- Scripts de package.json corregidos (puntos → dos puntos)
